HTML BASICS

HTML stands for Hyper Text Markup Language. It is the standard markup language for creating web pages and web applications. HTML describes the structure of a web page using markup. HTML elements are represented by tags, which are enclosed in angle brackets. The content of an HTML element is placed between the opening and closing tags.

List types

Lists are a collection of items. They can be ordered (like a shopping list) or unordered (like a to-do list).
